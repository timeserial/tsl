# Experiments - pre-registration artifacts

These scripts are the pre-registered protocols cited (by commit hash)
in the paper. Their FILENAMES are kept exactly as first committed, in
Portuguese, to preserve provenance: renaming them would break the
paper-to-repository mapping. Translation table:

| filename term | meaning |
|---|---|
| `luta` / `luta3` | fight / fight 3 (the pre-registered duels vs BPTT) |
| `luta_justa` | fair fight (parameter- and budget-matched) |
| `preregistada` | pre-registered |
| `emenda2` | amendment 2 (declared control correction) |
| `dados_virgens` | virgin (held-out) data |
| `finais` | finals (the deciding runs) |
| `profundidade_empilhamento` | depth / stacking experiment |
| `frente2_intercalacao` | front 2: regime interleaving |

Each script's internal comments are in English; the protocol each one
implements is described in the paper's methods section, and the
pre-registration commit for each fight predates its results in the
git history.
